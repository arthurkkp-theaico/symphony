Control plane

Issue Tracker

Jira or Linear holds the ticket, status, comments, and handoff state.

Daemon container

Symphony Daemon

Polls, claims, dispatches, retries, blocks, and reports agent progress.

Isolation

Workspace

Per-ticket repo copy where hooks prepare dependencies and local state.

Codex process

Codex app-server

Stdio JSON-RPC process launched inside the ticket workspace.

Agent turn runtime

Codex agent

Runs turns inside app-server: edits, tests, tools, and PR work.

Visibility

Dashboard / API

Served by Symphony to show running, blocked, retry, and token state.
